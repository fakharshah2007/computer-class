# 🎓 Skill Computer Academy (Computer Class)

> An open, tuition-free digital literacy and computer education platform empowering individuals worldwide with essential technology skills, coding foundations, and verified digital credentials.

## 🌟 Highlights

- **100% Free Tuition**: Open educational curriculum accessible to anyone, anywhere.
- **Interactive Multi-Page Portal**:
  - **Home / Landing Page (index.html)**: Overview of learning paths, course tracks, student testimonials, and curriculum highlights.
  - **Course Details (course-details.html)**: Comprehensive syllabus breakdown, module objectives, and interactive enrollments.
  - **Student Dashboard (student-dashboard.html)**: Progress tracking, enrolled courses, certificates, and achievements.
  - **Brand Assets & Logo (logo.html)**: Academy vector branding, color palette, and visual identity specifications.
- **Modern Responsive Design**: Built with Tailwind CSS, Plus Jakarta Sans typography, and Google Material Symbols.

## 🚀 Getting Started

### Option 1: Direct Browser Access
Simply clone this repository and double-click index.html to open the academy in any modern web browser.

### Option 2: Local HTTP Server (Node.js)
If you have Node.js installed, start the built-in development server:
`ash
node server.js
`
Then visit http://localhost:3000 in your browser.

### Option 3: Python HTTP Server
`ash
python -m http.server 8000
`
Then open http://localhost:8000.

## 🌐 Deploying to GitHub Pages

1. Navigate to your repository on GitHub: https://github.com/fakharshah2007/computer-class
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch** (or use the included GitHub Actions workflow).
4. Select the **main** branch and **/** (root) folder, then click **Save**.
5. Your site will be live at:
   **https://fakharshah2007.github.io/computer-class/**
